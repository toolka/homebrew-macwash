# homebrew-macwash

Homebrew tap for [MacWash](https://github.com/toolka/MacWash) — macOS system cleaner CLI.

## Install

```bash
brew tap toolka/macwash
brew trust toolka/macwash
brew install macwash
```

## Usage

```bash
macwash clean          # Deep cache cleanup
macwash uninstall      # Remove apps + leftovers
macwash optimize       # Flush DNS, rebuild caches
macwash analyze        # Explore disk usage
macwash status         # Live system dashboard
```
